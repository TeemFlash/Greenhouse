Arduino CLI: сборка NodeMCU 1.0 / esp8266:esp8266:nodemcuv2 — PASS.
ESP8266 core 3.1.2, GC9A01A 1.1.1, GFX 1.12.6, BusIO 1.17.4.
ESP8266SdFat 2.1.1 из пакета платы выбран явно через --library,

IRAM + cache: 61451 / 65536 байт (93%).

показатель 49% не включает все динамические выделения Wi-Fi/SD/HTTP.

Сборка --warnings all: предупреждений в файлах проекта нет.
Два SyntaxWarning в штатном elf2bin.py пакета ESP8266 связаны с Python;
они не помешали сборке и не относятся к коду прошивки.

C++ модель управления: PASS, -Wall -Wextra -Werror,
AddressSanitizer и UndefinedBehaviorSanitizer.
Проверены калибровка, устаревшие измерения, нехватка воды, длительность
импульса, суммарный лимит, количество циклов, интервал, достижение цели,
защёлка ошибки I2C, ручной таймер, переход MANUAL -> AUTO без продления
импульса, гистерезис вентиляции по двум причинам, резервное поведение,
расписание через полночь, границы расписания, переполнение millis().
Дополнительно 20000 псевдослучайных шагов проверяют инварианты запрета
помпы при отказах/остановке и выключение команд при потере связи.

JavaScript встроенной веб-панели: node --check — PASS.
Это проверка синтаксиса, а не проверка работы HTTP на устройстве.

Прошивка загружена на ESP8266EX, flash 4 МБ, /dev/ttyUSB0.
Данные после записи проверены esptool: Hash of data verified.
Не проверены на стенде: изображение и плавность, сенсорные кнопки,
