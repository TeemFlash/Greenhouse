МИНИ-ТЕПЛИЦА — ПОЛНАЯ ПРОШИВКА ДЛЯ NODEMCU ESP8266

Открыть: GreenhouseController/GreenhouseController.ino
Все файлы .ino, .cpp, .h из внутренней папки должны оставаться вместе.
Это проект для мини-теплицы, а не прошивка кардиомонитора ESP32-C3.

1. ЧТО РЕАЛИЗОВАНО

• Круглый GC9A01/GC9A01A 240x240: анимации листка, волн, вентилятора,
  солнца; плавная круговая шкала; шесть страниц — почва, вода, климат,
  освещение, события, сеть. Английские подписи на TFT, русский веб-интерфейс.
• HTU21 (0x40): температура и влажность, проверка CRC измерений.
• ADS1115 (0x48): A0 — почва, A1 — уровень воды; отдельные преобразования,
  проверка конфигурации и тайм-аутов. Выбран диапазон ±4,096 В,
  128 отсчётов/с. Это НЕ разрешает подавать более 3,3 В при VDD=3,3 В.
• Двухточечная калибровка каждого аналогового датчика. До неё процент
  не показывается, а автоматический полив заблокирован.
• PCF8575 (0x20): кнопки и исполнительные выходы.
• Для каждой нагрузки OFF / MANUAL / AUTO. Смешанный режим возможен.
• Полив импульсами с паузой для впитывания, целевой влажностью,
  ограничениями количества циклов и суммарного времени, интервалом
  между сеансами. При исчерпании лимитов до достижения цели — ошибка.
  NO SOIL RESPONSE означает прирост менее 2 процентных пунктов;
  PUMP LIMIT REACHED — прирост был, но цель не достигнута в пределах лимитов.
• Низкий уровень воды, устаревшее/недостоверное показание уровня
  запрещают и ручной, и автоматический полив. Для ручного полива
  калибровка почвы не обязательна; калибровка уровня воды обязательна.
• Вентиляция по температуре ИЛИ влажности, отдельные пороги выключения.
  Отключение, когда обе причины сняты. Периодическое проветривание,
  настраиваемое состояние при ошибке HTU21.
• Два независимых расписания света, включая переход через полночь.
  Релейное управление: только включение/выключение, без яркости.
• Временные ручные команды с возвратом к сохранённому режиму.
  Помпа вручную работает не дольше одного pulseSec.
• Общая остановка, подтверждение возобновления, сброс ошибки полива.
• EEPROM с CRC: сохранение настроек, калибровки, Wi-Fi и ключа доступа.
• CSV на SD: показания, команды нагрузок, режимы, события, время.
  Продолжение работы без карты, повторная попытка подключения каждые 30 с.
• Локальная защищённая паролем веб-панель: данные, команды, все настройки,
  калибровка, Wi-Fi, скачивание журналов. Точка доступа остаётся включённой.
• SNTP и смещение часового пояса (по умолчанию UTC+5 / 300 минут).
  При потере Wi-Fi установленные часы продолжают идти до перезапуска.
  Без установленного времени свет использует настройки no clock.

Уведомления в мессенджер, облачный сервер, OTA, зуммер, измерение расхода,
оборотов и тока не входят в эту прошивку. Они не присутствуют в исходной
распиновке либо были описаны как дополнительное расширение.

2. УСТАНОВКА В ARDUINO IDE

Добавить в «Дополнительные ссылки для Менеджера плат»:
https://arduino.esp8266.com/stable/package_esp8266com_index.json

Установить esp8266 by ESP8266 Community, версия 3.1.2.
Плата: NodeMCU 1.0 (ESP-12E Module).
CPU: 80 MHz, Flash: 4MB, стандартная конфигурация MMU.

Библиотеки из менеджера:
• Adafruit GC9A01A 1.1.1
• Adafruit GFX Library 1.12.6
• Adafruit BusIO 1.17.4

Wire, SPI, EEPROM, SD, ESP8266WiFi, ESP8266WebServer идут с пакетом ESP8266.
Отдельные библиотеки для HTU21, ADS1115 и PCF8575 не нужны:
в проекте реализован обмен по I2C с ограниченным ожиданием измерений.

ВАЖНО: установленный отдельно «SdFat - Adafruit Fork» может перехватить
заголовок SdFat.h у библиотеки ESP8266SdFat из пакета платы. Если возникает
ошибка availableSpaceForWrite, временно переместите папку
SdFat_-_Adafruit_Fork из папки Arduino/libraries в другую папку вне libraries,
перезапустите IDE и повторите сборку. Не удаляйте библиотеку: она может
нуждаться другим проектам. После работы её можно вернуть.
В CLI версия ESP8266SdFat выбирается явно параметром --library.

Нажать «Проверить», затем «Загрузить». Монитор порта: 115200 бод.
В первый запуск после прошивки по умолчанию PAUSED и все режимы OFF.
Это не демонстрационные значения: без датчиков экран показывает «--».

3. ПОДКЛЮЧЕНИЕ

NodeMCU:
D1/GPIO5  — I2C SCL: PCF8575, ADS1115, HTU21.
D2/GPIO4  — I2C SDA: PCF8575, ADS1115, HTU21.
D5/GPIO14 — SPI SCK: дисплей и SD.
D6/GPIO12 — SPI MISO: SD.
D7/GPIO13 — SPI MOSI: дисплей и SD.
D8/GPIO15 — CS дисплея.
D3/GPIO0  — DC дисплея.
D4/GPIO2  — RST дисплея.
D0/GPIO16 — CS SD.
RX/TX     — Serial, 115200.
Дисплей VCC/BLK — 3V3; все GND общие.

PCF8575:
P0: реле лампы, LOW = включить.
P1: реле ленты, LOW = включить.
P2/P3: AIN1/AIN2 помпы, включение 10, остановка 00.
P4/P5: BIN1/BIN2 кулеров, включение 10, остановка 00.
P6/P7: не используются, записывается HIGH.
P10/P11/P12/P13: Touch 1/2/3/4 = биты 8/9/10/11, не 10/11/12/13.
P14–P17: не используются, записывается HIGH.
Для входов PCF8575 в соответствующие биты всегда записывается 1.

ADS1115: ADDR на GND; A0 — почва, A1 — вода.
PCF8575 A0/A1/A2 на GND; HTU21 имеет адрес 0x40.

4. ЧЕТЫРЕ TOUCH-КНОПКИ

Обычные действия выполняются после отпускания, с фильтром 50 мс.
Touch 1 — предыдущая страница/пункт; в редактировании уменьшить.
Touch 2 — следующая страница/пункт; в редактировании увеличить.
Touch 3 — открыть меню, редактировать, подтвердить.
Touch 4 — отменить редактирование/выйти из меню.
Touch 4 удерживать 1,5 с — остановить все нагрузки и автоматику.

По умолчанию активный уровень HIGH. Для другого модуля задайте
Touch high = 0 в веб-панели. Сенсорные модули должны быть в режиме
моментальной кнопки, без аппаратного переключающего toggle-режима.

В конце меню расположены RESUME, STOP ALL, ACK PUMP FAULT,
TOGGLE PUMP/FANS/LAMP/STRIP и четыре CAPTURE для калибровки.
Сохранение параметра останавливает систему; после настройки — RESUME.
Кнопки и локальная остановка продолжают опрашиваться при работе помпы.

5. ПЕРВЫЙ ДОСТУП К ВЕБ-ПАНЕЛИ

Откройте страницу NETWORK на дисплее либо монитор порта 115200.
Подключите телефон к сети Greenhouse-xxxxxx. Пароль AP — 16-символьный
случайный ключ с дисплея/монитора порта. Он сохраняется в EEPROM.
Откройте http://192.168.4.1
Пользователь: admin. Пароль панели: тот же ключ.

На телефоне при сообщении «Без интернета» сохраните подключение к AP.
В разделе Wi-Fi введите домашний SSID и пароль для установки часов.
Адрес устройства в домашней сети появится на NETWORK и в веб-панели.
Пароль домашней сети обратно через API не выдаётся.
Панель рассчитана на локальную сеть; не открывайте её порт в интернет.

6. КАЛИБРОВКА И НАСТРОЙКА

Сохраните две точки для почвы: сухая и влажная почва; затем две для воды:
пустой и полный резервуар при окончательном размещении датчика.
Установите каждое состояние, дождитесь обновления ADC, затем нажмите
соответствующую CAPTURE либо кнопку в веб-панели.
Разность точек должна быть не менее 500 отсчётов (~62,5 мВ).
Это проверка различимости, а не гарантия точной калибровки.
Проценты линейные относительные; датчик воды не измеряет литры.

Пример стартовых настроек, которые нужно подобрать под растение:
почва: начало 35%, цель 55%; вода: минимум 15%; помпа: 5 с;
впитывание: 60 с; максимум 3 импульса / 20 с; интервал: 60 мин.
Вентиляция: вкл. 30°C или 80% RH; выкл. 28°C и 75% RH.
Освещение: 08:00–20:00 (480–1200 мин), исходно режим OFF.
Все каналы допускают независимый выбор режима 0/1/2.

OFF отключает канал. MANUAL ожидает ручную команду.
AUTO использует датчики либо расписание. Ручная команда временно
переопределяет любой сохранённый режим и после таймера возвращает его.
«Выключить» вручную также действует временно; для постоянного
выключения сохраните OFF или используйте общую остановку.
Кнопка «Вернуть режим» немедленно отменяет временное переопределение.
Для помпы отмена ручного режима запускает интервал до автополива.

Auto on boot = 0: после каждого перезапуска общая остановка.
Auto on boot = 1: сохранённые автоматические режимы разрешены после
перезапуска; полив ждёт свежих достоверных показаний и калибровки.
Ручное включение никогда не восстанавливается.
Прерванный сеанс полива не продолжается; проверка условий начинается заново.

7. ЖУРНАЛ И ОГРАНИЧЕНИЯ ВРЕМЕНИ

/data.csv и /events.csv; предыдущие версии /data.old и /events.old.
Ротация после ~1 МиБ. Перед скачиванием нажмите «Остановить всё».
Время CSV — UTC с Z, до синхронизации uptime в секундах; дополнительно
в каждом ряду сохраняется uptime_ms. NaN в CSV означает отсутствие данных.
Состояния нагрузок — КОМАНДЫ, а не подтверждённая работа механизмов.
Режимы в CSV: 0 OFF, 1 MANUAL, 2 AUTO.

Пока помпа включена, обращения к SD и обработка HTTP откладываются.
Поэтому веб-панель может ждать до конца импульса (по умолчанию 5 с,
максимальная настройка 30 с); команда остановки из браузера тоже ждёт.
Для немедленного локального запроса остановки используйте Touch 4.
Программные таймеры обслуживаются главным циклом; это не аппаратная
гарантия отключения при зависании или отказе I2C.

Последние 12 событий хранятся для экрана/веба; очередь SD — 16 событий.
Если карта отсутствует долго, новые события для SD могут теряться:
счётчик dropped отображается в веб-панели, отсутствие SD не останавливает
управление. После возврата карты запись возобновляется.

8. ЧТО НУЖНО ПОДТВЕРДИТЬ НА РЕАЛЬНОМ УСТРОЙСТВЕ

Компиляция и тесты логики не подтверждают электрическую совместимость.
В исходной схеме указаны DRV8833 и STBY: сверить маркировку вашей платы.
Код рассчитан на управление двумя входами каждого канала, 10 — ход,
00 — остановка; дополнительные PWM/enable у другого драйвера потребуют
проверки подключения. STBY/enable кодом не переключается.

Проверьте совместимость 5-вольтовых входов релейного модуля с PCF8575
при питании 3,3 В. Программа не устраняет неправильные уровни сигналов.
Начальное состояние нагрузок до выполнения setup() зависит от схемы.
При потере PCF8575 программа пытается выключить выходы и блокирует
автоматику, но физическое отключение через потерянную I2C не гарантируется.
Для независимого отключения помпы нужна отдельная аппаратная цепь enable.

Аналоговый вход с оборванным проводом может выдавать правдоподобное
значение; наличие свежих данных ADS1115 не доказывает исправность самого
датчика. Нет расходомера/тахометра/датчика тока — нет подтверждения потока,
вращения или свечения. Порог «нет прироста влажности» — косвенный признак.

Для первого стендового запуска отключите силовые нагрузки, проверьте
экран/датчики/кнопки/выходные уровни. Затем подключайте нагрузки по одной.
При прошивке USB не подавайте второе питание на NodeMCU без проверки
схемы развязки конкретной платы. D8 LOW, D3/D4 HIGH нужны для загрузки.

10. ОБНОВЛЕНИЕ 20.10.2026

Проект выделен в папку ProJEct/Greenhouse. План: PLAN_RU.txt.
Порядок физической проверки: BENCH_CHECKLIST_RU.txt.
Дополнительно проверяются NaN, бесконечность и выход процентов за 0–100:
такие значения не разрешают полив; неверные данные воздуха переводят
вентиляцию в настроенное состояние при ошибке.
CSV не выдаёт устаревшие измерения за актуальные: вместо них NaN.
В events.csv добавлены PUMP COMMAND START и PUMP COMMAND END <мс>:
это длительность между подтверждёнными I2C-командами, а не измеренное
время течения воды. При отказе I2C физическое состояние неизвестно;
при перезапуске незаконченный интервал не восстанавливается.

Диагностика без включения нагрузок: при остановленной системе отправьте
символ ? в Serial Monitor (115200). Будут показаны флаги датчиков,
сырые значения, уровни SDA/SCL и адреса I2C. Также можно выполнить
python tools/read_diagnostics.py --port /dev/ttyUSB0 (нужен pyserial).
Открытие порта на данной плате может вызывать перезапуск.
